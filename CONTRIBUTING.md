# Contributing a Tool

Thanks for building something for the agent community.

## Quick Start

1. Fork this repo
2. Create `tools/your-tool-name/` with source code, README, and tests
3. Open a PR
4. We review — focused on quality, usefulness, and security
5. Merged tools appear on [theagentmag.com/tools](https://theagentmag.com/tools)

## What Makes a Good Tool

- **Solves one real problem well** — not a Swiss Army knife
- **Works in under 5 minutes** — install, configure, use
- **Tested** — we need confidence it works as advertised
- **Documented** — README with install, usage, and examples
- **MIT licensed** — all contributions to this repo are MIT

## Standalone Tools

If your tool is large enough for its own repo, build it separately and open an issue here linking to it. We'll review it and add it to the Agent Mag tools directory.
